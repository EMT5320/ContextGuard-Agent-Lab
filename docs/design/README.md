## 3. 当前原则

- 设计审稿期优先暴露问题，暂缓堆实现。
- 所有核心能力必须落到 metric、trace、report 或 case card。
- 公开项目不使用公司数据和内部策略。
- 项目主张收敛前，README 只保留 honest draft wording。
